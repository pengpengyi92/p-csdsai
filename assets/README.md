# P-CSDSAI cover art

[`p-csdsai-super-workspace.webp`](p-csdsai-super-workspace.webp) is the 2:1
README cover, made with the built-in image generator and converted to WebP
without cropping or resizing. The public
[P-ML cover](https://github.com/pengpengyi92/P-ML/blob/fc6a8aff0afa51ccb63013dffc0c05328f96eb45/assets/p-ml-research-lab.webp)
provided the Xiao G mascot and illustration style. The plots and diagrams are
illustrative, not research data or implementation claims.

## Generation prompt

> Use case: illustration-story. Create an original panoramic 2:1 GitHub README cover for P-CSDSAI, a collaborative computer science, data science and AI super-workspace. Transform the supplied P-ML illustration. Preserve only Xiao G's recognizable cream-and-ginger chibi cat design, the green bandana with a single G, and the warm hand-painted gouache technique. Redesign the room, props and robots for this new scene.
>
> Exactly four Q-version characters actively collaborating at one long shared workbench, all with large clear faces: the small Xiao G cat in the center, a teal “CS” robot at left, a periwinkle “DS” robot next to the cat, and an amber “AI” robot at right. The three robot chest badges must spell exactly “CS”, “DS”, “AI”, no other characters. Xiao G is comparing the team's evidence in an open notebook and giving feedback on a shared touchscreen. Everyone looks engaged, not posed.

A small jointed tabletop robot arm (plain lab apparatus, not a fifth character) moves a colored block as the embodied AI example. A feedback hand-touch icon linking the cat's shared screen to the agent panel suggests human-AI collaboration.
>
> Full shared room: stacked books, screens, one tidy rack of computing hardware, data sheets and wires, with plenty of breathing room around faces. Clear readable colored badge lettering, no extra headlines, slogans, captions, logos, copyright marks or watermarks. Stylized visual shorthand, not realistic technical diagrams. Warm friendly storybook gouache, sunlit hardware lab, muted blue-green with amber, lilac, muted coral and warm paper colors. All 4 faces are large and readable on a GitHub mobile README. Keep screens behind and beside the cast, not in front of their faces.
