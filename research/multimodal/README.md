# 多模态研究模块

**Author:** Pengyi Peng / P-CSDSAI

**Established:** 2026-11-19 (Asia/Shanghai)

**Status:** Public-source engineering research; comparisons NOT_RUN / UNMEASURED.

多模态的单位不是扩展名，而是可回溯证据：视频片段、声学事件、图片区域、PDF 页和表格、文档结构、以及这些证据之间的时间和引用关系。此模块设两条互相连接、但不混淆任务和指标的路线。

| 路线 | 仓库整理 | 专题报告 | 主要问题 |
| --- | --- | --- | --- |
| 多文件、多模态 RAG | [24 个工程来源](../../repo/multimodal/README.md) | [从文件解析到可回溯证据](../../report/2026-11-19-multimodal-rag.md) | 找到对的页、时间段和区域，并忠实回答 |
| World Model | [12 个分类来源](../../repo/world-models/README.md) | [从表征预测到闭环决策](../../report/2026-11-19-world-models.md) | 在动作/条件下预测状态并支持可测决策 |

范围包括 video、audio、image、PDF、DOCX、PPTX、HTML、Markdown、表格和混合文件。**不承诺每一个项目支持每一种格式**：具体支持依赖固定版本、解析后端、模型和可选组件。支持矩阵须由真实样本验证，不能从 README 的一句 all-in-one 推断。

## 第一期工作台

- RAG：先用原创/授权的 24 份固定材料建立带页号、框和时间区间的 gold evidence；按文档/录音/视频来源分组，冻结开发与审计集合，禁止同文件切片泄漏。
- World Model：先选定一个版本固定、可获取状态的控制环境；用相同交互/离线数据、动作约定、种子和决策时延预算比较，不跨任务合并所谓总榜。
- 工程：PPRT 做独立小修复；PR 提交、维护者接受、端到端模型效果是三类证据。记录公开 PR，不复制私有原始日志。
