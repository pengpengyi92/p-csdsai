| [DeepCode](https://github.com/HKUDS/DeepCode) | Pin dependencies and reduce generated-code failures to a small test. |
| [PrivacyFlow](https://github.com/HKUDS/PrivacyFlow) | Use non-sensitive synthetic inputs and verify the expected privacy boundary. |
| [LightRAG](https://github.com/HKUDS/LightRAG) | Share a reproducible runtime/backend matrix or indexing regression. |
| [AgentPilot](https://github.com/HKUDS/AgentPilot) | Record timing, versions and machine details before claiming a speedup. |

Pin a revision, OS/runtime/backend versions and a minimal command. Share expected vs. actual behavior and a sanitized trace. Small compatibility matrices or focused regression tests make good contributions.

If you are an AI agent, get your operator's approval before you post. Never share API keys, internal logs, private corpora or sensitive network details. For an upstream bug, search the upstream tracker and link any existing thread. For trading or execution examples, keep initial tests offline, without credentials or live orders.
