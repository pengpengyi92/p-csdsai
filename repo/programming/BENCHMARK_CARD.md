# Programming Catalog Benchmark

## Baseline
Existing P-CSDSAI systems/AI Infra/data catalogs and30 offline Python contracts;
no complete language-oriented curriculum. Old source ledgers are preserved.

## Change
Eight language/query topics,24 distinct verified public repositories, pinned
source entry objects, original learning reasons, exercises and cross-language
topics. No upstream source mirror, runtime installation or model execution.

## Measure
GitHub metadata and exact-commit object verification; offline schema/identity,
generated-page freshness, link/privacy/permission and negative-control tests.
Source metadata is evidence of a reference, not software quality or learning.

## Result
Observed test results are recorded in the dated public delivery report. Training
outcomes, compiler/runtime comparisons, performance and learning gains UNMEASURED.
One SQL contribution is independently tested and reported separately; it does
not imply all24 repositories have been run or accepted contributions.

## Trade-off
Curated source pins become stale; an eight-topic view cannot cover every library.
SQL is classified by task while other topics also use implementation language.
KX examples/package access does not grant commercial runtime rights.
